## Common Comand Line tool
The command of `mkdir` is use  **to make a folder** and the name of folder will be after `mkdir`.

For example: 

mkdir strawberry🍓
___
The command `touch` is use **to make a file** and file was ended with *.md or .txt* in the folder.

For example:

1. cd stawberry
2. touch ❤️red.md
3. touch 🤍white.txt
---
The command `list` is just like it name **list folder in the directory**.

For example:

ls

Output: ❤️red.md 🤍white.txt
____
The command of `cd` is to *click in* the folder/file it is a **specified**.

For example:

cd stawberry

---
Now we were in stawberry we will use `pwd`

The command of `pwd` is for **seeing current location**

For example:

pwd
Output:
/workspace/strewbarry
